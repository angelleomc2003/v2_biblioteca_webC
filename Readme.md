# 📚 Proyecto Biblioteca - Django

## 🎯 Objetivo

Construir una aplicación web en Django que permita:
- Registrar autores y libros.
- Registrar reseñas para cada libro.
- Visualizar libros y sus reseñas.
- Aplicar conocimientos de modelos, ORM, URLs, administración y carga de datos iniciales.

## 🧩 Estructura del proyecto

- Proyecto Django: `biblioteca_project`
- Aplicación principal: `biblioteca`
